# Stupid Apps

One ridiculously simple, useless web app a week. Client-side only, no backend, no build step.

Live: https://stupid-apps.vercel.app

| Week | App | Joke |
| --- | --- | --- |
| 1 | [meeting-simulator](meeting-simulator/) | Your 1:1. Everyone talks over you. Only you get cut off. |
| 2 | [engagement-slots](engagement-slots/) | Pull a lever, win a painfully generic X post. |

Each app is a single folder. Open its `index.html` in a browser to run it.
